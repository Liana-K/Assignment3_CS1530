Projects

BeatTree

BeatTree is an easy BPM-based music browsing for DJs, producers, and anyone else who needs to find a match for their beats. It was built with React, CSS, and the Spotify API. From this project, I learned how to make dynamic, scalable web applications using the React framework and learned how to integrate an API into a web app.

JointScope

JointScope is a web-based recovery tool that uses video and pose estimation to measure joint range of motion, track progress over time, and recommend physio exercises for each stage of recovery. I built this with a hackathon group with React and CSS for the web app, and JavaScript for the backend logic. From this project, I learned how to integrate the laptop camera and use it for real-time input for our backend.
